# 🤖 Antigravity Telegram & PC Terminal Bridge

An interactive bridge that connects your **PC Terminal** and **Antigravity CLI (Gemini Pro)** to **Telegram** on your mobile phone.

With this bridge:
- 📱 **Send Prompts from Anywhere:** Send tasks, questions, or coding instructions from Telegram on your phone.
- 💻 **Live PC Terminal Feed:** Everything typed on Telegram or generated by the agent is displayed live in your PC terminal with rich ANSI colors.
- ⌨️ **Bidirectional Input:** You can also type directly in the PC terminal; the agent executes the task and syncs the conversation with your phone.
- 🔘 **Interactive Multiple Choice Buttons:** When the agent needs clarification or asks you to choose next steps, it automatically generates **clickable Telegram inline keyboard buttons** on your phone (and numbered options in the terminal).
- 🔒 **Secure Auto-Pairing:** Protects your machine so only your authorized Telegram account can control it.

---

## 🚀 Quick Setup

### 1. Configure your Telegram Bot Token
You mentioned you already have your Telegram Bot Token from `@BotFather`.

You can set it in `config.json`:
```json
{
  "bot_token": "YOUR_ACTUAL_BOT_TOKEN_HERE",
  "allowed_user_ids": [],
  "workspace_path": "/home/francesco/Progetti/AIbot",
  "agy_path": "/home/francesco/.local/bin/agy",
  "default_model": "gemini-2.5-pro",
  "dangerously_skip_permissions": true
}
```
*(If you run without setting it first, the script will politely prompt you to paste it in the terminal!)*

### 2. Launch the Bridge
In this folder (`/home/francesco/Progetti/AIbot`), run:
```bash
python3 main.py
```
*(or `bash start.sh`)*

### 3. Pair your Phone
1. Open Telegram on your phone and open the chat with your bot.
2. Send `/start`.
3. The bot will automatically pair with your Telegram user ID, display a welcome status with the active Gemini model and workspace path, and log the pairing in the PC terminal.

## 🎮 How It Works

### 1. Sending Prompts
- **From Phone:** Type any message in Telegram (e.g. `Create a FastAPI CRUD service for managing book inventory`). The agent starts running on your PC, keeps a "typing..." indicator active on your phone, and streams logs to the PC terminal.
- **From PC:** Type directly into the PC terminal and press `Enter`. The prompt is executed, printed locally, and a notification is sent to your phone.

### 2. Multiple-Choice Questions & Next Steps
Whenever Antigravity wants to ask clarifying questions or understand next steps (e.g.):
```
Which database would you like to use?
1. PostgreSQL with SQLAlchemy
2. SQLite with Peewee
3. MongoDB
```
The bridge automatically parses the options and sends **interactive buttons** to Telegram!
- **Tap a button on your phone**: The choice is immediately registered, confirmed with a checkmark (`✅ Selected: ...`), and forwarded to Antigravity to resume execution.
- **Or type `1`, `2`, or `3` in the PC terminal** to pick an option directly from your keyboard.

### 3. Telegram & Terminal Commands

| Command | Action |
| :--- | :--- |
| `/start` | Show status and pair user |
| `/status` | View current agent activity, active model, and workspace |
| `/new` or `/reset` | Clear context and start a fresh session |
| `/stop` or `/cancel` | Interrupt and stop the currently running turn |
| `/model <name>` | Switch model (e.g. `/model gemini-2.5-pro` or `/model gemini-2.5-flash`) |
| `/help` | Display command list |

## 💡 Built-in Alternative: `agy --remote-control`
If you ever want a quick web browser view without Telegram, Antigravity also features built-in remote control:
```bash
agy --remote-control
```
or typing `/remote-control` inside an active `agy` session. It generates a secure web tunnel that opens in any mobile browser!
